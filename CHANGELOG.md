# Changelog

All notable changes to the Angle Ideation Agent methodology and repository will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.9.0] - 2026-08-26

### Added
- **Multi-Niche Benchmark Showcase:** Highlighting verified transfer runs across running biomechanics (`StrideForm`), pet behavioral wellness (`Pawsitive Calm`), follicular scalp care (`FolliRoot`), and pediatric care (`Baby Bubble`).
- **Curiosity-First Creative Architecture:** Shifted conceptual framing across all quality gates and prompt templates from aggressive direct-response exploit terminology to curiosity-led, insight-driven creative strategy.
- **Unified Eval Harness:** Standardized automated evaluation harness across live benchmark runs, transfer runs, negative controls, and synthetic fault-injection cases.

## [1.6.1] - 2026-08-14

### Changed
- **A-VILLAIN:** Prohibited situational loops as the subject; villain must be a relocatable object, tool, habit, or advice pattern.
- **A-DOOR:** Tightened the product-as-doorway rule; prohibited product unboxing or chamber admiration as the emotional dream climax.

## [1.4.0] - 2026-08-13

### Added
- **Creator–Verifier Triad:** Initial separation of Generator (`00`–`05`), Critic (`06_gate_report`, `06_gold_scores`), and Red-Team Adversary (`07_adversary`).
- **AngleFuel Contract:** Scenario A (rich qualitative dossier) and Scenario B (thin inputs) ingestion engine.
